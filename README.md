# 🎛️ Media Compressor – Python Project

A lightweight Python GUI tool for compressing audio, video, and image files with ease. Built using **Tkinter**, this app allows quick file selection and adjustable compression settings through a simple interface.

---

## 🛠 Features

- 🎵 **Audio Compression**: Supports `.wav`, `.flac`, `.mp3` by reducing sample rate  
- 🎬 **Video Compression**: Supports `.mp4`, `.avi`, `.mov` using custom bitrate  
- 🖼️ **Image Compression**: Supports `.jpg`, `.jpeg`, `.png`, `.bmp` with quality adjustment  
- 🖱️ Easy-to-use GUI for selecting files and setting parameters  
- 📢 Real-time status messages after compression completes

---

## 💻 Technologies Used

- **Python 3.x**  
- **Tkinter** – GUI  
- **moviepy** – Video compression  
- **soundfile** – Audio processing  
- **Pillow (PIL)** – Image compression
